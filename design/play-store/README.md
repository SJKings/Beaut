# Google Play listing assets

From the Claude Design bundle. Upload in Play Console → Grow → Store presence → Main store listing.

| File | Use |
|---|---|
| `icon-512.png` | App icon (512×512) |
| `feature-graphic-1024x500.png` | Feature graphic |
| `phone-1.png` … `phone-6.png` | Phone screenshots (1080×1920) |
| `tablet7-1.png`, `tablet7-2.png` | 7-inch tablet screenshots |
| `tablet10-1.png`, `tablet10-2.png` | 10-inch tablet screenshots |
| `logo-*.png` | Brand logos (not uploaded to Play) |

The in-app icons in `app/assets/` are redrawn from `icon-512.png` at 1024 px
(adaptive foreground/monochrome layers keep the mark inside Android's safe zone).
