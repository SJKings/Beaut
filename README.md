# Beaut

Beauty-care booking with no sign-up: every booking gets a unique code used to find, reschedule or cancel it.

- [`app/`](app/) — the guest mobile app (Expo / React Native). See [`app/README.md`](app/README.md) to run it.
- [`design/`](design/) — the Claude Design handoff bundle: HTML prototypes for the app and the studio dashboard, plus the design chat.
